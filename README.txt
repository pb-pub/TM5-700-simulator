TM5-700 Simulator

This repository contains a MATLAB-based simulator for the TM5-700 robotic arm. The simulator includes tools for forward and inverse kinematics, workspace visualization, and robot motion simulation.

How to Run

Running the App: 
1. Open terminal
2. run : matlab -r "run('robotSimulation.mlapp');"
or 
1. Open MATLAB.
2. Navigate to the folder containing this repository.
3. Run the "robotSimulation.m"lapp script by typing the following command in the MATLAB Command Window:
   robotSimulation


Running the Main Script:
1. Open MATLAB.
2. Navigate to the folder containing this repository.
3. Run the "main.m" script by typing the following command in the MATLAB Command Window:
   main
4. Follow the instructions displayed in the Command Window or observe the visualizations generated by the script. 
You have 4 choices  :
   1. Forward Kinematics
   2. Inverse Kinematics
   3. Visualize Robot Workspace
   4. Motion Planning
5. If you want to see the actual motion you can uncomment the 73rd line of "main.m" but be careful it is pretty long to compute. The generated gif is attached in this folder.


Files:
Part 1: 
- "robotSimulation.mlapp": MATLAB apps for interacting with the simulator.
- "main.m": Main script for running the simulation.
- "forward.m", "inverse.m": Functions for forward and inverse kinematics.
- "mdh.m", "dh_parameters.m", "areAnglesRight.m": Utilities for parameters or modified DH matrixs.
- "drawRobot.m", "drawWorkspace.m": Visualization utilities.

Part 2:
- `compute_theta.m` — Generates a joint angle at time t for a move A → B → C (handles accel/steady/decel phases).
- `cost.m` — Computes a weighted squared difference between two joint-angle vectors (lower is better).
- `motion_planning.m` — Demo: gets poses, computes IK, picks a smooth solution, creates trajectories, and plots results.
- `points_and_times.m` — Provides target poses for A/B/C and timing parameters used by the planner.
- `modulate_angles.m` — Adds ±360° variations to solutions when allowed by joint limits to cover equivalent poses.
- `select_combination.m` — Picks the best A/B/C solution set by minimizing the cost between poses.
- `show_motion.m` — Plots robot and traces end-effector path for a trajectory matrix.
- `make_gif.m` — Saves an animation of the robot motion as a GIF.
 - `animate_motion.m` — Plays the robot motion in a given axes without saving a GIF (frame-by-frame animation).




Requirements:
- MATLAB R2023a or later.
